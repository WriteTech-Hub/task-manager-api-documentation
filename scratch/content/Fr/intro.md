# Bienvenue dans la documentation de la Task Manager API

Cette documentation vous aide à comprendre, intégrer et tester la **Task Manager API**, qui alimente les fonctionnalités d'authentification, de suivi des tâches, de rôles utilisateurs et de rapports.

Vous pouvez explorer :

- **Authentification** – Découvrez comment vous inscrire, vous connecter et sécuriser les requêtes.
- **Tâches** – Gérez les tâches avec des opérations CRUD, des priorités et un suivi de la progression.
- **Utilisateurs** – Comprenez les rôles et les permissions des utilisateurs.
- **Rapports** – Accédez aux points de terminaison de synthèse et d'analyse.

👉 Commencez par consulter la section [Authentication API](./api/authentication).
